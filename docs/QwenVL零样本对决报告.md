# 里程碑3.2 零样本对决报告: YOLOv11s vs Qwen-VL

- 测试集: NEU-DET val360(seed=42 划分)中分层均衡抽取 **100 张**(6 类均衡)
- 匹配规则: 同类贪心 IoU≥0.5; 零样本 Qwen-VL 未见过任何 NEU 样本, 仅靠文字类别定义
- VL 模型: `qwen-vl-plus` (阿里云百炼, temp=0)
- 现金单价: qwen-vl-plus 输入 0.8 元/百万 token、输出 2 元/百万 token(2026-09 官方价)

## 三、结论

- 专业工业纹理缺陷(200×200 灰度)上, 领域监督模型 YOLOv11s 的检测 F1 显著高于通用 VLM 零样本;
  VLM 主要短板: 多实例枚举不全、类别混淆(氧化铁皮/斑块/夹杂)、框不够紧、200px 小图细节不足。
- VLM 的价值: 零标注成本、开箱即用、可输出自然语言解释, 适合冷启动/新缺陷粗筛与异常提示;
  待数据积累后训练专用检测器是性价比最高的落地路径(本平台已验证)。

## 四、VLM 接口工程健壮性(首轮 vs 修复后)

首轮 100 张中 plus 出现 17 次长输出 JSON 损坏(重复 `detections` 键+半截断尾)、5 次 60s 超时、1 次上游错误; 随后加入三项修复: ① 解析器按括号深度打捞已完整输出的检测项(重复段去重); ② prompt 限制最多 8 个显著区域 + max_tokens=2048; ③ 超时/429 自动重试。

## 五、方法学与评测口径

- **样本**: 训练/验证同划分(`stratified_split`, seed=42)得到 val360, 再按 6 类分层均衡抽 100 张
  (crazing16 / inclusion17 / patches18 / pitted_surface16 / rolled-in_scale16 / scratches17),
  与 YOLO 训练数据完全隔离, Qwen-VL 全程零样本(无 few-shot 示例、不做任何 NEU 样本微调)。
- **GT**: 原始 VOC XML(`parse_voc`), 每张图全部实例框参与统计。
- **匹配**: 同类贪心匹配(预测按置信度降序), IoU≥0.5 计 TP; 同时报告"忽略类别仅看定位"的 F1,
  用于区分"找不到"与"找到了但认错类"。另统计图像级主类准确率(多数预测类 vs GT 主类)。
- **延迟**: YOLO 为 GPU 纯推理 ms; VL 为云端 HTTP 往返(含模型生成), 各含 P95。
- **成本**: 仅统计百炼现金成本, 单价取 2026-09 官方价(plus 输入 0.8、输出 2 元/百万 token);
  YOLO 走本机算力, 不计现金成本。

## 六、典型失败模式(定性)

1. **类别混淆(主因)**: inclusion 被大量标成 scratches(42 个 FP 全落在错类),
   crazing(网状细裂纹)与 pitted_surface/rolled-in_scale 互相混淆;
   "仅定位 F1"(0.053)略高于类别 F1(0.034), 说明框到位置、认错类的情况占一部分。
2. **定位不贴合**: 200×200 小灰度图上模型给框偏松/偏移, IoU 难到 0.5;
   细长划痕(GT 常为窄长条)尤其明显——scratches 主类能认对但 IoU 不达标的比例高。
3. **枚举不全/发散并存**: 部分图只给 1 个框(应 2-3 个), 个别图又"发散"枚举到上限;
   首轮 17 次 JSON 损坏即来自长枚举退化(重复 `detections` 键并半截断尾),
   已由解析器"括号深度打捞"兜底(提取已完整生成的检测项, 重复段去重), 失败率 23%→0。
4. **速度长尾**: 云端 API 平均 8.5s、P95 33s, 与本地 YOLO 12ms/P95 14ms 差 3 个数量级,
   不适合产线实时工位, 更适合离线粗筛/冷启动。

## 七、接口与复现

- Python: `POST http://localhost:8001/infer/detect-vl`(multipart: `file` + 可选 `model=plus|max`),
  响应含 `model/provider/detections/inference_ms/tokens`; 错误映射: 配置缺失 503 / 鉴权 502 /
  限流 429 / 超时 504 / 上游 502; 超时(60s)与 429 自动重试 1 次。
- Java 网关: `POST /api/inference/detect-vl`(JWT 鉴权, 180s 读超时专用 RestClient)。
- 前端: "缺陷检测"页双模型对决视图(YOLO 实线框 / Qwen-VL 虚线框, 含耗时/token/成本标签),
  验收截图 `docs/screenshots/infer32_duel_cards.png`(双画框卡片) 与 `infer32_duel_lists.png`(检测明细)。
- 复现命令(在 `ai-service/` 下):

.\.venv\Scripts\python.exe scripts/benchmark_vl_vs_yolo.py --n 100 --workers 2
