## 一、项目概览

### 1.1 项目目标
面向智慧制造场景的 AI 钢材表面缺陷智能质检平台，用于 AI 应用开发 / 大模型 / 智能体方向求职展示。项目刻意避开已有项目的 RAG 问答 / Agent / MCP 能力，主攻**多模态视觉检测 + 数据集工程 + 模型训练评估 + 推理服务化 + LLM 结构化报告 + 向量溯源**等差异化能力。

### 1.2 技术栈一览
| 层 | 技术 |
|---|---|
| 后端 | Spring Boot 3.5 + Java 21 + Spring Security + JWT + MyBatis-Plus |
| 数据存储 | MySQL 8 + Redis 7 + MinIO(图像) + Milvus(向量) |
| AI 服务 | Python 3.11 + PyTorch 2.x + Ultralytics(YOLOv11) + Qwen-VL + FastAPI |
| 前端 | Vue3 + Vite + TypeScript + Ant Design Vue + ECharts + Vue Flow |
| 监控 | Micrometer + Prometheus + Grafana |
| 部署 | Docker Compose + GitHub Actions |
| 大模型 | 通义/DeepSeek 云端 API 为主 + Ollama 本地兜底 |

#### 阶段 1 踩坑（详见项目记忆 5.4）
1. **albumentations 2.x `A.Rotate` 对贴边大框旋转会产生碎片框**（crazing_1 的 191×192 框 1→5 框，全量 4189→7288）。解法：改用 `A.Affine(rotate=±15, border_mode=BORDER_CONSTANT)` + `BboxParams(min_visibility=0.5)`，全量 4189→4176 无重复
2. **父 POM 未继承 spring-boot-starter-parent，缺 `-parameters`**：`@RequestParam` 省略 value 时反射拿不到参数名报 500。已在父 POM 显式配置 maven-compiler-plugin `<parameters>true</parameters>`；改后须 `mvn clean package`（增量打包曾混入旧 class，且 Windows 下先停 jar 再打包避免文件锁）
3. **a-card `:loading` 骨架屏会销毁/重建卡片内容 DOM**：echarts 实例绑定旧游离节点导致图表不渲染。图表卡片改用 `<a-spin :spinning>`（只加遮罩不换 DOM）
4. **a-menu-item 不会自动路由**：需在 a-menu 上 @click → router.push(key)（阶段0仅一个菜单未暴露）
5. 预签名 URL 按 GET 签名，HEAD 测试会 403（签名方法不匹配），浏览器 img 标签 GET 正常
